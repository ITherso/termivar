# Criterion baseline: `f7d5120`

> **Historical suite:** this commit predates the platform quarantine. The
> response-cache, WAF-detection, and double-encoding benchmarks below no longer
> exist and must not be compared with the current suite.

This is the first evidence-backed Venom microbenchmark baseline. It was captured by the green [Quality Metrics workflow run](https://github.com/ITherso/venom/actions/runs/30648542265) for commit [`f7d5120`](https://github.com/ITherso/venom/commit/f7d5120741ae1c2328e1b82b6cec50664a947528).

## Criterion results

| Benchmark | Mean | 95% confidence interval |
| --- | ---: | ---: |
| Response cache hit, 4 KiB | 213.71 ns | 213.00–214.86 ns |
| WAF header detection | 152.28 ns | 151.27–153.99 ns |
| Double URL encoding | 3.113 µs | 3.106–3.124 µs |

Command:

```bash
cargo bench --locked -p venom-scanner --bench scanner_benchmarks -- --noplot
```

The suite took 58 seconds of runner wall time and recorded 550,932 KiB peak RSS. These whole-process values include compilation and harness overhead; they are not per-operation memory measurements.
